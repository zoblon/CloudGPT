# Branding

The public CloudGPT mark is an original AI-generated arrangement of intertwined blue cloud ribbons, created for this project. It is not Apple's official iCloud logo or OpenAI's official logo. The older private artwork was derived from Apple's iCloud symbol; no claim of original authorship is made for that artwork, and it is not included in this public snapshot.

`assets/cloudgpt.png` is the transparent standalone mark; `assets/icon.png` is the package compatibility icon; `assets/social-preview.png` is the repository preview (1280×640). The plugin copies the same mark into its asset folder. Keep these copies synchronized.

The project name is retained by the maintainer; OpenAI's [brand guidelines](https://openai.com/brand/) restrict GPT in product names. This notice is not permission from OpenAI or Apple.

Generated artwork is supplied with the repository under its MIT terms to the extent rights are available. No exclusive trademark rights or legal clearance are claimed. See [Apple's guidelines](https://www.apple.com/legal/intellectual-property/guidelinesfor3rdparties.html).

For GitHub social preview, upload `assets/social-preview.png` under repository Settings → General → Social preview. GitHub recommends 1280×640; see [GitHub documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
