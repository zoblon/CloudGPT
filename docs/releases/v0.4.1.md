# CloudGPT 0.4.1

First public source release, based on the tested 0.4.0 core.

- English README, setup guide, plugin instructions, terminal prompts and developer documentation.
- New project cloud icon and GitHub social preview, replacing Apple-derived artwork.
- Unbound public cloud-plugin template. A personal app binding is included only when explicitly supplied to a local build, whose output is labeled `-bound.zip`.
- Packages include the project license and exact tunnel-client release provenance.
- Private history and older account-bound releases remain in a separate private repository.

Existing runtime, configuration, Keychain, tunnel and launchd identifiers are compatible. Unpack separately and use **Update.command** on the Mac running the service. Refresh the ChatGPT connection and separately update any private wrapper/skill. This repository does not automatically update a running installation.

The source and real bundled MCP protocol are checked with synthetic credentials and simulated endpoints. Real iCloud connections, Automation consent, Mac login and iPhone/iPad use remain installation-specific checks. The Mac must be awake and online.

CloudGPT is independent and is not affiliated with Apple or OpenAI.
