# CloudGPT 0.4.2

## One installer for setup and updates

Open **Install CloudGPT.command** after unpacking the macOS release. On a new Mac, it collects settings and Keychain credentials, installs the login service and waits for tunnel readiness. With an existing service, it automatically uses the safe updater with a full runtime backup and readiness-based rollback. A completed setup can be resumed without entering credentials again.

Incomplete packages, invalid existing settings and inconsistent partial installations are rejected before changing the service. The existing individual commands remain available for diagnostics and advanced use. Configuration paths, Keychain entries, tunnel permissions and server access modes are unchanged.

The installer updates the Mac service. Refresh the ChatGPT connection afterward; update the account-bound ChatGPT plugin separately to replace its logo and skill. The public cloud-plugin ZIP is still an unbound template.

No production installation on the maintainer's other Mac is implied by the package build or synthetic tests.
